DRONE.IO v7 멀티플레이 테스트

[같은 와이파이에서 친구와 테스트]
1. 이 폴더에서 터미널/명령 프롬프트를 엽니다.
2. Node.js가 설치되어 있어야 합니다.
3. 처음 한 번: npm install
4. 실행: npm start
5. 내 PC에서는 http://localhost:3000 접속
6. 친구 PC에서는 http://내PC의_로컬IP:3000 접속
   예: http://192.168.1.23:3000
7. Windows 방화벽에서 Node.js 네트워크 접근을 허용해야 할 수 있습니다.

[내 로컬 IP 확인]
Windows 명령 프롬프트에서: ipconfig
IPv4 Address 항목을 확인하세요.

[멀리 떨어진 친구와 테스트]
이 프로젝트를 Render/Railway/Fly.io/일반 VPS 등에 올리면 됩니다.
Start Command: npm start
Port: 환경변수 PORT를 자동 사용합니다.

조작
WASD 이동
마우스 조준
클릭 발사
Q 폭탄 (고정 30 데미지)
E 포션
SPACE 부스트 (약 3초 연속 사용 가능)

현재 v7 목적
- 실제 플레이어 2명 이상 같은 맵 동기화
- AI 봇은 약하지만 더 적극적으로 추격/사격
- 필드 아이템, 야생 개체, 폭탄, 포션, 코인 유지
- 상대 플레이어 사망 시 보유 아이템의 약 20%가 필드에 드랍

주의
이 버전은 '친구와 손맛 테스트'용 MVP입니다. 계정 저장/치트 방지/정식 매칭/상점은 아직 없습니다.
